# Ruta para ser experto en Java

**Cómo usar este roadmap**
- El orden de la lista ES el orden de lectura. Cada línea es un archivo en su carpeta (= paquete en minúsculas).
- Cada archivo trata UN concepto a fondo: de cero a nivel técnico, ejemplo real justo debajo de cada punto, sin `println` de relleno, `main` solo con `check(...)`. Modelo: cualquier guía de `v2_oop/`.
- `← de ...` indica de qué archivo viejo se reutiliza y mejora el contenido.
- Nombres de archivos y carpetas en inglés; explicaciones en español. Las carpetas con más de 3 guías se dividen en subcarpetas numeradas `partN_name/` (Java no permite paquetes que empiecen con número); las pequeñas (como `v4_generics/`) no. Cada guía lleva en su encabezado `Ruta / Anterior / Siguiente`.
- Un archivo viejo se borra solo cuando TODO su contenido ya vive en su nuevo lugar (ver tabla al final).
- **`Main.java` (raíz, tus notas) se queda exactamente como está.** No se modifica, no se mueve, no se borra.
- Las carpetas principales llevan prefijo `vN_` para ordenarlas (`v1_fundamentals/` … `v5_collections/`); cada carpeta nueva toma el siguiente número.
- Marca `[x]` al terminar.
